# ayrank-mcp

An MCP server for the free [AY Rank tools API](https://www.ayrank.com/openapi.json). It lets an AI agent run the same checks as https://www.ayrank.com/tools: AI crawler access, robots.txt tests, sitemap and hreflang validation, page size, headers, headings and more. No API key needed.

Work in progress. The plan is in the open pull request.
